# Casa do Pet Rações

Site institucional/vitrine demonstrativo criado no padrão DevCLT.

- Sem backend, banco, login, carrinho ou checkout.
- WhatsApp demonstrativo: `3499152341`.
- Endereço, horários, produtos, serviços e demais dados comerciais são ilustrativos.
- As imagens fornecidas pelo usuário foram incorporadas em `img/`.
- Abra `index.html` diretamente no navegador.
